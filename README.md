Entry for make.fun's **"One Line, Zero Use: The Useless Superpower Sprint"**. The program writes a single original one-liner (73 characters) describing a hilariously useless superpower to `/output/entry.txt`:

> I can teleport anywhere in the world, as long as it's within arm's reach.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
